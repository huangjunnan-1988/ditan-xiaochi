# 全国地摊小吃大全

205 个全国地摊小吃配方 · 精确到克 · 一键生成采购单 · 全国 48 城 995 个选址点位 · 付费解锁完整版

## 功能
- **配方库**：11 大类 205 配方，五维筛选，灵魂层克数精确到克且可溯源（地方团体标准/官方规范/多平台商用配方）
- **一键采购单**：按日销量自动换算采购量（克→斤/两），跨配方同原料合并汇总，复制/打印/下载 CSV
- **全国选址**：48 城 318 区 995 个点位（摊位类型/租金/客流时段/城管办证/来源 URL）
- **付费墙**：预览引流，解锁码解锁完整克数（防君子不防小人的轻保护方案）

- 数据口径：成本按 2026 年常见批发价估算，需本地复算；"待补/需实测校准/待核实"为如实标注，未编造
